# PRODIGY_WD_05 — Weather Application 🌦️



## 📌 About

A simple weather web app that fetches **real-time weather data** using the **OpenWeatherMap** API and displays it in a clean, modern UI.

---

## ✨ Features

✔ Search weather by city
✔ Get weather using current location
✔ Shows temperature, humidity, wind & pressure
✔ Error handling for invalid city
✔ Responsive and lightweight design

---

## 🛠️ Tech Stack

* HTML5 — Structure
* CSS3 — Styling & Responsive Layout
* JavaScript — API calls & Interactivity
